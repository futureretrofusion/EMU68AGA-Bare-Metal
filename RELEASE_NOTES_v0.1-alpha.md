# EMU68AGA Version 0.1-Alpha — Raspberry Pi 3

18 October 2026 — experimental tester build.

Boot footer: **EMU68AGA Version 0.1-Alpha**. The git string has been removed from the displayed footer.

Keyboard reported working. USB mouse does not currently work on cold boot, gamepad pairing does not yet result in Amiga/MAME input, USB mass storage mounting works but writes remain unverified. USB hub timing and device recovery are experimental.

Pi 3 FAT boot bundle includes kernel8.img and required Raspberry Pi firmware, DTBs, overlays, config and floppy.txt. Does not include AmigaOS/Kickstart. Back up before installing.

Bug reports: **futureretrofusion1984@gmail.com**. Include Pi model, setup, reproducible steps and results.

The matching source is in machine/ at this release tag. Existing third-party licensing notices are retained.
