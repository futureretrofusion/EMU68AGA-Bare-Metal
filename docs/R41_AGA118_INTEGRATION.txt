INSTALL FOR HARDWARE TEST
1. Back up the current working boot FAT32 kernel8.img.
2. Copy BOOT/kernel8.img to the boot partition as kernel8.img.
3. Boot and verify the POST says:
   TINYUSB PI3 / R41 AGA118
4. Confirm the previously fixed USB gamepad still works without holding fire.
5. Install C/agaboot as C:agaboot.
6. Install C/whdwrap if used.
7. Install Utilities/AGA-SoundMonitor as SYS:Utilities/AGA-SoundMonitor.
8. Test Workbench/RTG handoff, native AGA games, HDMI sound, PAL/NTSC switching, CRT/flicker/scanline settings and WHDLoad.
